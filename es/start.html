Aprender

Aprende Loment

Instala el paquete, haz que un programa se ejecute y elige la ruta que encaje con tu forma de trabajar: dos libros —uno para usar Loment y otro para cambiarlo—, un conjunto de ejemplos o un curso de ejercicios. Cada programa se compila y se ejecuta en la puerta de calidad. Debajo de todo hay otro maestro: una cadena de herramientas que se explica sola, capaz de imprimir todo el lenguaje, listar cada función incorporada y decir qué significa cualquier diagnóstico.

Leer el libro Abrir el Playground

La enseñanza existe; falta la traducción. Loment Book, Development Contribution Plan, By Example y Lomentlings están en inglés; el manual de referencia y los registros de diseño siguen en chino. Cuando un recurso de abajo está incompleto, esta página lo dice.

Instalación

Loment se distribuye como paquete. Toma el archivo de tu plataforma desde la última versión.

Linux / WSL

linux-x64.tar.gz. Descomprímelo y ejecuta sh install.sh. Solo hace falta POSIX sh.

Windows

windows-x64.zip: descomprímelo y ejecuta powershell -File install.ps1, o windows-x64-setup.exe, que se abre con doble clic.

Obtienes el comando loment, el gestor de paquetes (lompi) y el servidor de lenguaje. Compilar y ejecutar no necesita Python, clang ni WSL: el paquete son binarios nativos y la biblioteca estándar, y el instalador verifica SHA256SUMS antes de escribir nada.

Para cambiar el lenguaje en sí en lugar de usarlo, parte de una copia de trabajo: git clone https://github.com/Loment-Lang/loment.git. El compilador está escrito en Loment y se reconstruye desde una semilla confirmada en el repositorio; sh loment/bootstrap.sh lo construye y comprueba que la semilla se reproduce byte a byte.

Escribe un programa

Pon esto en hello.lomt. 

module hello fn _start() {    let s: str = "hello from Loment\n";    syscall4(1, 1, str_ptr(s) as u64, str_len(s) as u64);    syscall4(60, 0, 0, 0);}

_start es donde empieza la máquina. Un programa sellado —que no enlaza nada— no tiene una runtime debajo que llame a un punto de entrada por ti, así que lo nombras tú; y no tiene printf, así que la salida va por la llamada al sistema write: el descriptor de archivo, el puntero a la cadena y su longitud. La segunda llamada es exit. Escribe choose hosted y obtienes un programa C normal, con fn main() -> u32 como punto de entrada.

Compílalo y ejecútalo

$ loment run hello.lomt          # compile, link, run$ loment build hello.lomt -o hello$ loment check hello.lomt        # check only, nothing written$ loment ir hello.lomt           # the LLVM IR it generates

En Windows el objetivo es PE, así que nombra la salida .exe: el enlazador elige el formato por ese nombre. loment new hello escribe este punto de partida y no sobrescribe un archivo existente.

Elige una entrada

Dos libros y dos itinerarios prácticos, un lenguaje. Elige el que encaje con lo que necesitas; todos están en el repositorio y cada programa se comprueba en la compilación.

Loment Book

Apodado «el libro». Explica el lenguaje desde primeros principios y construye algunos proyectos por el camino, así que al final tienes un modelo funcional de la sintaxis, los dominios de capacidad y lo que el compilador hace con tu fuente.

Development Contribution Plan

El segundo libro: el mapa del repositorio, la puerta de calidad y sus trinquetes, los dos compiladores y su semilla, la cadena de arranque, las versiones y un recorrido por la arquitectura. Léelo cuando quieras cambiar Loment, no solo usarlo.

Loment by Example

Un concepto por archivo, cada uno un programa corto y anotado que compila y se ejecuta. Úsalo cuando necesites una forma que funcione en lugar de una explicación.

La cadena de herramientas se explica sola

Esta es la parte realmente poco habitual, y merece la pena probarla aunque no pienses usar el lenguaje. La cadena de herramientas es la referencia. Todas estas órdenes leen del paquete instalado, así que funcionan sin red y responden sobre la versión que tienes. 

$ loment example tour   # the whole language in one file$ loment cheat          # the whole language on one page$ loment builtins       # every built-in function there is$ loment syntax         # syntax summary$ loment explain E4     # what a diagnostic means, and what to change

Los comentarios de tour están en chino, y en la versión publicada actual ese archivo no enlaza; los programas de la página de ejemplos son los verificados. Las otras cuatro órdenes están en inglés.
