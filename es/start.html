Primeros pasos

Esta página solo trata de conseguir que un programa se ejecute y verlo funcionar. Para qué sirve el lenguaje está en la página principal.

Instalar la extensión de VS Code

Instálalo

Loment se distribuye como un paquete. Toma el archivo de tu plataforma de la última versión.

Linux / WSL

Un linux-x64.tar.gz. Descomprímelo y ejecuta sh install.sh. POSIX sh es el único requisito.

Windows

Un windows-x64.zip — descomprímelo y ejecuta powershell -File install.ps1 — o un windows-x64-setup.exe al que haces doble clic.

Obtienes el comando loment, el gestor de paquetes (lompi) y el servidor de lenguaje. Compilar y ejecutar no necesita ni Python, ni clang, ni WSL: el paquete son binarios nativos más la biblioteca estándar, y el instalador comprueba SHA256SUMS antes de escribir nada.

Para cambiar el lenguaje mismo en lugar de usarlo, parte de una copia de trabajo: git clone https://github.com/Loment-Lang/loment.git. El compilador está escrito en Loment y se reconstruye a partir de una semilla confirmada en el repositorio — sh loment/bootstrap.sh lo construye y comprueba que la semilla se reproduce a sí misma byte por byte.

Escribe un programa

Pon esto en hello.lomt. 

module hello fn _start() {    let s: str = "hello from Loment\n";    syscall4(1, 1, str_ptr(s) as u64, str_len(s) as u64);    syscall4(60, 0, 0, 0);}

_start es donde arranca la máquina. Un programa sealed — uno que no enlaza nada — no tiene runtime debajo que llame a un punto de entrada por ti, así que lo nombras tú mismo; y no tiene printf, así que la salida pasa por la llamada al sistema write: el descriptor de archivo, el puntero de la cadena y su longitud. La segunda llamada es exit. Escribe choose hosted en su lugar y obtienes un programa C corriente, con fn main() -> u32 como punto de entrada.

Compílalo y ejecútalo

$ loment run hello.lomt          # compile, link, run$ loment build hello.lomt -o hello$ loment check hello.lomt        # check only, nothing written$ loment ir hello.lomt           # the LLVM IR it generates

En Windows el destino es PE, así que nombra la salida .exe — el enlazador elige el formato a partir de ese nombre.

Explora el lenguaje

El conjunto de herramientas se explica a sí mismo. Estos cuatro cubren casi todo. 

$ loment example tour   # the whole language in one file$ loment cheat          # the traps, ordered by how easily they bite$ loment builtins       # every built-in function there is$ loment syntax         # syntax summary

loment example tour imprime todo el lenguaje como un único archivo fuente comentado. Sus comentarios están en chino, y en 0.1.4 ese archivo en particular no enlaza; los cuatro programas de Ejemplos son los que están verificados para ejecutarse.
