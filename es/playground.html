Qué se ejecuta en esta página

    
El código se compila con el compilador de referencia del repositorio y después lo ejecuta LVM, el intérprete que el proyecto usa para sus pruebas deterministas en tiempo de ejecución. Los dos pasos ocurren en esta pestaña.

    
Límites. La primera ejecución descarga unos 20 MB de motor. El programa puede usar fn main() o fn _start(). La entrada estándar, los archivos y los sockets no están disponibles, y un límite de pasos detiene un bucle descontrolado. Loment no tiene MIR ni HIR: AST es el módulo analizado, Potato es el objeto de forma y Código máquina es un listado hexadecimal del .text de lomelf. Canal elige la instantánea del compilador: Beta sigue el último main (0.1.5.2.beta.2) y Estable es 0.1.5.1. La salida Wasm está prevista para 0.1.5.2 (#1496).

    
Para instalar la cadena nativa, empieza en Primeros pasos. Hay más programas en Ejemplos.
