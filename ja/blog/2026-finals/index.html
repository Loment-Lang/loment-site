2026年の終点

私は 2026 年の最後の数週間を、短いリストに使っています。0.1.5.2 の正式版、0.1.5.3 の 最初のテストビルド、道具らしく感じる Playground、そしてライフタイムと GC タイミングの もう一巡です。これはそのリストの長い版です。

これは私が進めている計画です。今日の安定チャネルはまだ 0.1.5.1 です。 順序はありますが、日付はありません。

2026 年が置いたもの

2026 年はプロジェクトを 0.1.4 から 0.1.5.1 へ運びました。表層文法には三つの版次が あります。Tur 2026.1 は凍結、Tur 2026.2 は十一月に封じられ、Tur 2026.3 は私がまだ 動かしている版です。ファイルは自分がどの版として読まれるかを固定できます。それが この仕組みの目的でした。

ドメインは入って出るブロックになりました。入れば始まり、出れば終わります。十八種類が すべて出荷され、domain:for は位置を歩き、木とグラフの辺も文法になりました （child_of、couple、mutex）。LSPE v2 は四つの 部品で来ました。質問器（E1–E8）、逆質問器（Q001–Q013）、LSPC のプリフライト表、 そして各サイトの証明ハッシュと .lspe の副ファイルを持つ台帳です。

借用ライフタイムはライフタイム記法なしで入りました。&T と &mut T は引数、戻り値、構造体フィールド、ジェネリック引数で一次型です。 tur2026.3 以降は lifetime_auto が既定で、よくある形には 注釈が要りません。自前コンパイラは 2026-11-08 に追いつき、E041 はいまや領域が成立 しないときだけ出ます。lgc はコレクタに時計を与えました。 lgc start(10ms) { … } は協調的な予算つきの収集ウィンドウを開き、 lgc end; は一時停止します。no_gc と lgc の 組み合わせは、制御するコレクタがないので E039 です。

store は 13 パッケージ、332 モジュール、2791 個の公開関数になりました。私は ChaCha20、 Poly1305、AEAD、AES-CTR/GCM、x25519、ed25519、SCM_RIGHTS 付きの AF_UNIX、TLS 1.3 クライアントの中核、イベントループ、原子的なファイル操作、有界 channel、ジョブキュー、小さな HTTP サーバー、Windows の宣言面を追加しました。 Playground は参照コンパイラと LVM をブラウザのタブに載せ、Java ライブラリは JVM なしで 呼べるようになり、ホットアップデートはリリースの形になり、wasm32 は設計記録になりました。

開いている一覧は最後の節に置いています。私はそれを丸めずに出すほうが好きです。

最後の区間の順序

順序は短いです。まず 0.1.5.2 を正式版にします。beta 線はすでに ドメイン、LSPE v2、ライフタイム次元、拡張された store、Playground のスナップショットを 載せています。正式化の週には、チャネル、成果物、署名、ノートが互いに一致している必要が あります。私は、両実装が同じ表層を読み、判据がすべて緑になったときに安定チャネルを 動かします。

次に、0.1.5.3 が最初のテストビルドで開きます。私は次の線を、年を 終わりと呼ぶ前に動かせる形にしたいです。テストビルドは、まだ設計のものが最初の実行可能な 形を得る場所です。安定した床が先にあれば次のビルドを評価しやすいので、私はこの順序を 守っています。

「正式版」のいちばん役に立つ意味はたぶん狭いものです。タグ、署名された成果物、Stable が 指せるチャネル、そして何が欠けているかを書いたノート。それが開いている設計項目をすべて 閉じるわけではありません。一覧は最後の節に残り、対応する判据ができるまでそこにあります。

同じ数週間の三本の線

Playground

私は次の数週間を Playground に使っています。ほとんどの人が最初にコンパイラに会う場所 だからです。初回ロードを速く、スナップショットを小さくしたい。行番号、文法、診断、選択を 正しく保つエディタが欲しい。Run、Check、Build、IR、AST、Potato、マシンコードの動作を もっと明確にしたい。phone でも使えるレイアウトが欲しい。Beta は main を 追い続け、Stable はリリースタグを指し続けます。アップロードもサーバーもありません。

ライフタイム

私は lifetime_manual を &a T の印の外へ広げ、借用を ジェネリック引数として両実装に持ち込み、診断が出所、行、経路を名指しするようにして います。たぶん注釈なしの形が既定のままで、明示する形は稀で明白であるべきです。

GC タイミング

私は lgc の予算の意味を詰め、四段の梯子でコレクタを測り、各段が負荷の下で 何を約束するかを書き留めています。予算が制限するのは収集の開始であり、実行中の収集を 横取りはしません。no_gc は本物のモードのままで、no_gc と lgc の組み合わせは E039 のままです。

ここでの「終点」の意味

学年は暦があるから期末試験で終わります。言語は違う終わり方をします。私は表層が動かなく なり、判据がすべて緑になったときに版を閉じます。十二月は立ち止まって見るには良い時期で、 仕事が終わったと宣言する理由にはなりません。

たぶん、正直な年末の文はローンチより小さいものです。私は何も作り話をせずに一ページで プロジェクトを説明できます。それが来年に欲しい基準です。

まだ開いているもの
