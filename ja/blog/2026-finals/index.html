2026年の終点

2026 年は終わりに近づき、最後の区間には具体的な計画があります。0.1.5.2 の正式版、 0.1.5.3 の最初のテストビルド、より良い Playground、そしてライフタイムと GC タイミングの 次の一巡です。これはその計画の長い版です。この年が実際に作ったもの、暦が変わる前に出す もの、まだ開いているもの。

これは計画であり、リリースノートではありません。今日の安定チャネルは まだ 0.1.5.1 です。順序は決まっていますが、日付は決まっていません。「正式版」はタグと 署名のあるチャネルを指し、すべての設計項目が閉じたという意味ではありません。

2026 年が実際に置いたもの

2026 年はプロジェクトを 0.1.4 から 0.1.5.1 へ動かしました。表層文法は二段階の版次に なりました。Tur 2026.1 は凍結、Tur 2026.2 は十一月に封じられ、Tur 2026.3 が開いている 線です。これは見た目のバージョン番号の変更ではありません。ファイルが自分をどの版として 読むかを固定でき、最新の文法が古い成果物を黙って変えずに進めるということです。

ドメインは場所とライフタイムを持つブロックになりました。入ればドメインが始まり、出れば 終わります。十八種類がすべて出荷され、domain:for は位置を歩きます。木と グラフの辺も文法になりました（child_of、couple、 mutex）。LSPE v2 は四つの部品で来ました。質問器（E1–E8）、逆質問器 （Q001–Q013）、LSPC のプリフライト表、そして各サイトの証明ハッシュと .lspe の副ファイルを持つ台帳です。

借用ライフタイムはライフタイム記法なしで入りました。&T と &mut T は引数、戻り値、構造体フィールド、ジェネリック引数で一次型です。 tur2026.3 以降は lifetime_auto が既定で、よくある形には注釈が 要りません。自前コンパイラは 2026-11-08 に追いつきました。借用型を見ただけで E041 を 出すことはもうなく、E041 は領域が成立しないときだけ出ます。lgc はコレクタに 時計を与えました。lgc start(10ms) { … } は協調的な予算つきの収集ウィンドウを 開き、lgc end; は一時停止します。no_gc と lgc の 組み合わせは、制御するコレクタがないので E039 です。

store は 13 パッケージ、332 モジュール、2791 個の公開関数に増えました。直近のまとまりで ChaCha20、Poly1305、AEAD、AES-CTR/GCM、x25519、ed25519、SCM_RIGHTS 付きの AF_UNIX、TLS 1.3 クライアントの中核、イベントループ、原子的なファイル操作、有界 channel、ジョブキュー、小さな HTTP サーバー、Windows の宣言面が入りました。Playground は 参照コンパイラと LVM をブラウザのタブに載せ、Java ライブラリは JVM なしで呼べるようになり、 ホットアップデートはリリースの形になり、wasm32 は願いから設計記録になりました。

それが一年を一ページにしたものです。言語は約束の集合から、検査でき、リンクでき、出荷 できる成果物の集合になりました。

最後の区間には順序がある

2026 年の終わりの計画はわざと短くしています。まず 0.1.5.2 が正式版になります。 beta 線はすでにドメイン、LSPE v2、ライフタイム次元、拡張された store、Playground の スナップショットを載せています。正式化は新しい機能ではなく、チャネル、成果物、署名、 ノートが互いに一致する点です。両実装が同じ表層を読み、判据がすべて緑になったときだけ 安定チャネルは動きます。

次に、0.1.5.3 が最初のテストビルドで開きます。これはテストビルドであり、 リリースではありません。次の線が動かせる形になり、まだ設計のものが最初の実行可能な形を 得る場所です。順序が大事です。安定した 0.1.5.2 が先にあれば、次のビルドには固定された 床があります。自分の安定チャネルより先に走るテストビルドは、間違った教訓を教えます。

「正式版」の意味はここでは狭いものです。タグ、署名された成果物、Playground の Stable 側が 指せるチャネル、そして何が入っていないかを書いたリリースノートを指します。開いている設計 項目がすべて閉じたという意味ではありません。開いている一覧は最後の節にあり、対応する 判据ができるまで開いたままです。

同じ数週間の三本の線

Playground

Playground はほとんどの人が最初にコンパイラに会う場所なので、次の一巡はそこからです。 目標は具体的です。初回ロードを速く、スナップショットを小さく。行番号、文法、診断、選択を 正しく保つエディタ。Run、Check、Build、IR、AST、Potato、マシンコードの動作をより明確に。 そして phone でも使えるレイアウト。二つのチャネルは残します。Beta は main を 追い、Stable はリリースタグを指します。Playground はソースをアップロードせず、サーバーも 持ちません。

ライフタイム

ライフタイムは入りましたが、表層はまだ完成していません。次の一巡では lifetime_manual を &a T の印の外へ広げ、借用を ジェネリック引数として両実装に持ち込み、診断が「lifetime error」とだけ言うのではなく、 出所、行、経路を名指しするようにします。注釈なしの形が既定のままで、明示する形は 稀で明白であるべきで、第二の方言になってはいけません。

GC タイミング

lgc はコレクタに時計を与えました。次はその時計を予測可能にすることです。 予算が制限するのは収集の開始であり、実行中の収集を横取りはしません。次の一巡では 予算の意味を詰め、四段の梯子でコレクタを測り、各段が負荷の下で何を約束するかを書き留め ます。no_gc は罠ではなく本物のモードのままです。no_gc と lgc の組み合わせは E039 のままです。

ここでの「終点」の意味

学年は暦があるから期末試験で終わります。言語はそうではありません。版は表層が動かなく なり、判据がすべて緑になったときに封じられるのであって、十二月が来たから封じられる わけではありません。だから「2026 年の終点」は立ち止まって見る場所であり、仕事が終わった という宣言ではありません。

0.1.5.2 の正式版はタグのついたチェックポイントです。0.1.5.3 の最初のテストビルドは次の線が 動き始めることです。どちらも Tur 2026.3 を封じず、開いている一覧を消しもしません。正直な 年末の文はローンチより狭いものです。このプロジェクトは今、何も作り話をせずに一ページで 説明でき、次のページもすでに書かれています。

まだ開いているもの

一覧は隠していません。lifetime_manual にはまだ広い注釈の面が要ります。拡張 ドメインとグラフモデルの実体部分は設計のままです。wasm32 バックエンドは設計記録であり、 使えるバックエンドではありません。store のプラットフォームとプロトコルの縁は境界として 書かれ、Windows モジュールは PE FFI を待っています。五つの store の缺口はリリースではなく ブランチのままです。どれにも日付はありません。
