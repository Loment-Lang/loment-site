学ぶ

Loment を学ぶ

パッケージを入れ、1 つのプログラムを動かし、自分の進め方に合う道を選んでください。 2 冊の本（Loment を使うための本と、Loment を変えるための本）、 サンプル集、演習コースがあります。中のプログラムはすべて ゲートがコンパイルして実行します。その下にあるもう一人の教師が、 自分を説明するツールチェーンです。言語全体を印字し、すべての組み込み関数を 一覧し、診断の意味を教えます。

本を読む オンライン実行を開く

教材はあります。足りないのは翻訳です。 Loment Book、Development Contribution Plan、By Example、Lomentlings は英語です。リファレンスマニュアルと設計記録は まだ中国語です。以下で不完全な資料は、そのことをこのページに書きます。

インストール

Loment はパッケージとして配布されます。 最新リリースから 自分のプラットフォームのアーカイブを取ってください。

Linux / WSL

linux-x64.tar.gz。展開して sh install.sh を実行します。 必要なのは POSIX sh だけです。

Windows

windows-x64.zip を展開して powershell -File install.ps1 を実行するか、 windows-x64-setup.exe をダブルクリックします。

loment コマンド、パッケージマネージャー lompi、言語サーバーが 入ります。コンパイルと実行に Python、clang、WSL は不要です。パッケージは ネイティブバイナリと標準ライブラリで、インストーラーは書き込む前に SHA256SUMS を検証します。

言語自体を変えたい場合はチェックアウトから始めます: git clone https://github.com/Loment-Lang/loment.git。コンパイラは Loment で 書かれ、リポジトリにコミットされたシードから再構築されます。 sh loment/bootstrap.sh がビルドし、シードがバイト単位で再現するか確認します。

プログラムを書く

これを hello.lomt に置きます。 

module hello fn _start() {    let s: str = "hello from Loment\n";    syscall4(1, 1, str_ptr(s) as u64, str_len(s) as u64);    syscall4(60, 0, 0, 0);}

_start はマシンが始まる場所です。何もリンクしない密封プログラムには、入口を 呼ぶランタイムが下にありません。だから自分で名前を付けます。printf もないので、出力は write システムコールへ送ります。ファイル記述子、文字列のポインタ、長さです。 2 回目は exit です。choose hosted と書けば、入口が fn main() -> u32 の普通の C プログラムになります。

コンパイルして実行

$ loment run hello.lomt          # compile, link, run$ loment build hello.lomt -o hello$ loment check hello.lomt        # check only, nothing written$ loment ir hello.lomt           # the LLVM IR it generates

Windows のターゲットは PE なので、出力名を .exe にします。リンカーはその名前 から形式を選びます。loment new hello はこの出発点を書き出し、既存ファイルは 上書きしません。

入口を選ぶ

2 冊の本と 2 つの練習線、1 つの言語。必要なものに合うものを選んでください。どれも リポジトリにあり、中のプログラムはビルドが検査します。

Loment Book

「あの本」と呼ばれます。言語を第一原理から説き、途中でいくつかプロジェクトを作るので、最後には構文、能力ドメイン、コンパイラがソースに何をするかの動くモデルが手に入ります。

本を読む

Development Contribution Plan

2 冊目です。リポジトリの地図、ゲートとそのラチェット、2 つのコンパイラとシード、ブートストラップ鎖、リリース、アーキテクチャ巡検。Loment を使うだけでなく変えたいときに読みます。

貢献計画を読む

Loment by Example

1 ファイルに 1 概念。どれもコンパイルして実行できる短い注釈付きプログラムです。説明より動く形が欲しいときに使います。

By Example を見る

Lomentlings

直す小さな壊れたプログラム。1 つに 1 つの考え。終わったら教えるランナー付きです: python tools/lomentlings.py。構文が身につきます。

Lomentlings コースをする

ツールチェーンは自分を説明する

ここが本当に珍しい部分で、言語を使うつもりがなくても試す価値があります。 ツールチェーンがリファレンスです。どれもインストール済みパッケージから 読むので、ネットワークなしで動き、実際に持っているバージョンについて答えます。 

$ loment example tour   # the whole language in one file$ loment cheat          # the whole language on one page$ loment builtins       # every built-in function there is$ loment syntax         # syntax summary$ loment explain E4     # what a diagnostic means, and what to change

tour のコメントは中国語で、現在のリリースではそのファイルはリンクできません。 サンプルページのプログラムが実行確認済みです。残りの 4 コマンドは 英語です。

オンライン実行 ブラウザで Loment をコンパイルして実行。インストール不要。 サンプル このサイトの短いプログラムと、実際に出た出力。 Wiki 言語とツールチェーンを 1 トピック 1 ページで。 QUICKSTART.md このページの長い版。すべてのビルド経路を含みます。 Discord プロジェクトが話す場所。質問も不具合報告と同じく歓迎です。
