学习

学习 Loment

先安装，让一个程序跑起来，然后按你的方式选路：两本书（一本讲怎么用 Loment，一本讲怎么改 Loment）、一套示例，或者一门练习课。里面的每个程序都由门禁 编译并运行。所有这些之下还有另一位老师：一条会解释自己的工具链——它能打印 整门语言、列出全部内建函数，并说明任何一条诊断是什么意思。

读这本书 打开在线编译

教材已经在了，缺的是翻译。 Loment Book、Development Contribution Plan、 By Example 与 Lomentlings 是英文；参考手册与设计记录仍是中文。下面哪份材料不完整，这一页 会直接写明。

安装

Loment 以安装包形式发布。从 最新发布取对应平台的压缩包。

Linux / WSL

linux-x64.tar.gz。解包后运行 sh install.sh。 只需要 POSIX sh。

Windows

windows-x64.zip——解包后运行 powershell -File install.ps1——或者双击 windows-x64-setup.exe。

你会得到 loment 命令、包管理器（lompi）和语言服务器。编译与运行 不需要 Python、clang 或 WSL：安装包是原生二进制加标准库，安装器在写任何 文件之前会校验 SHA256SUMS。

要改语言本身而不是使用它，请从检出开始： git clone https://github.com/Loment-Lang/loment.git。编译器用 Loment 写成， 从仓库里的种子重建——sh loment/bootstrap.sh 会构建它，并检查种子能否逐字节 复现自己。

写一个程序

把下面这段放进 hello.lomt。 

module hello fn _start() {    let s: str = "hello from Loment\n";    syscall4(1, 1, str_ptr(s) as u64, str_len(s) as u64);    syscall4(60, 0, 0, 0);}

_start 是机器开始的地方。封闭程序——不链接任何东西——下面没有运行时替你调用 入口，所以入口由你命名；它也没有 printf，输出走 write 系统调用： 文件描述符、字符串指针和长度。第二次调用是 exit。改成 choose hosted，你得到的就是普通 C 程序，入口是 fn main() -> u32。

编译并运行

$ loment run hello.lomt          # compile, link, run$ loment build hello.lomt -o hello$ loment check hello.lomt        # check only, nothing written$ loment ir hello.lomt           # the LLVM IR it generates

Windows 上目标是 PE，所以输出名写 .exe——链接器按这个名字选格式。 loment new hello 会替你写出这个起点，并且不会覆盖已有文件。

选择一条路径

两本书、两条练习线、一门语言。挑符合你需要的那条；它们都在仓库里，里面的每个程序都由 构建检查。

Loment Book

人称“那本书”。它从第一原理讲语言，并沿途搭几个项目，最后你会对语法、能力域以及编译器对你的源码做了什么有一个可用的模型。

读这本书

Development Contribution Plan

第二本书：仓库地图、门禁及其棘轮、两个编译器与它们的种子、自举链、发布，以及一次架构巡览。想改 Loment 而不只是用它时读它。

工具链会解释自己

这是真正不寻常的部分，即使你不打算用这门语言也值得试。工具链就是参考。 下面每一条都从已安装的包里读，所以离线可用，而且回答的是你实际拥有的那个版本。 

$ loment example tour   # the whole language in one file$ loment cheat          # the whole language on one page$ loment builtins       # every built-in function there is$ loment syntax         # syntax summary$ loment explain E4     # what a diagnostic means, and what to change

tour 的注释是中文，在当前发布版里那个文件链接不过；示例页上的 程序是验证过能跑的。其余四条命令是英文。
