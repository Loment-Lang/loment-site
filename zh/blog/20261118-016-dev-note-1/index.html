0.1.6 开发笔记 #1

0.1.5.x 已经合上，0.1.6 也不再是路线图上的一行。这是第一篇关于它内部正在动什么的笔记，写法就像我站在工作台边跟人解释。

笔记记录一个时刻，不是一次发布。下面有些东西在参考实现里、还不在自举实现里；有些只是设计，背后还没有代码。每一段都会说清楚是哪一种。

函数现在是一个值

你可以把函数放进变量、传给另一个函数、把它返回，也可以通过变量调用它。闭包可以捕获身边的值：按值捕获，或者在你写明引用时按引用捕获。通过值调用和按名字调用写法完全一样，代码读起来没有区别；只有编译器知道其中的不同。

这个能力放在一个新的开关 choose fp 后面，默认关闭。关着时，产物与以前逐字节相同。打开后，编译器再也看不全每个调用目标，于是它收集程序取过地址的函数，并拒绝那种找不到同类型目标的间接调用。这条检查就是这项能力的代价，而且它被明明白白写出来。

编译器可以替你把类型拿过来

let x := e 与 let x: auto = e 现在是同一件事：局部变量的类型来自初始化表达式。第一版守一条很紧的规则——初始化表达式必须在某处写出类型：一个变量、一个参数、一条字段链、一次完整的转换，或者 true、false。裸字面量、调用和运算符一律拒绝。有几个内建函数返回的类型在源码里没有写法，如果一边猜、另一边拒绝，一点小方便就会变成两套构建之间的差异。这个特性属于 Tur 2026.3 及以后；旧版次保持原来的答案。

错误可以在发生的地方处理

catch 过去只给一个兜底值，别的什么都不给。现在它还能接住错误并跑一小段表达式——catch |e| { … }——或者用 catch return 把失败变成提前返回。编译器本来就有这两种形状要用的 switch 和载荷槽，所以代价很小，错误路径也仍然留在你写下的代码里。

类：从骨架到真正的派发

一个类会降成一个结构体：父类字段排在前面，后面是自己的字段；方法则是以类名开头的普通函数。单继承、字段、非虚方法、self 与构造在参考实现里已经能用。虚方法随后到位：虚继承层次在对象最前面带一张表，override 占固定槽位，super 直接调用父类，抽象方法只有签名没有函数体，子类的引用可以用在要求父类的地方。

两条边界要说清楚。虚类需要 runtime，因为那张表是用分配器建起来的。自举实现还读不懂类；这部分工作是参考侧的。默认构建不变。

效应：第一片真正跑起来的部分

效应声明已经能解析一阵子了；缺的是让它们跑起来的那一半。现在有一小片能编译：处理器的分支以一次 resume 收尾。降级方式就是内联——perform 变成几个绑定加分支体，handle 变成它自己的函数体，于是编译器其余部分根本见不到处理器节点。没有续体对象，堆上也不分配任何东西，所以这一片在 no_runtime 配手动回收下也能工作。

这个形状之外的东西会按名字被拒绝：会捕获的、会中止的、resume 不止一次的处理器。两套实现都能读语法；运行期降级目前只在参考侧。

关于程序含义的第三种意见

这棵树里几乎所有判据都是拿两套实现互相比。这很擅长发现分歧，却找不到两边一起错的情形，而今年已经发生过两次。新的东西是一个用 Loment 从标准本身写出来的解释器；它不导入编译器、链接器或格式化器。它运行小程序，把结果与手写的期望值对照。它先覆盖标量，后来学会循环、break、continue、字符串和结构体。它已经找出两个版次之间一处真实的差异——一个版次接受对结构体字段赋值，另一个拒绝。两套实现意见一致时，正是这种东西它们没法告诉你。

审计框架不再是一堆检查

编译器的检查现在经过一张注册表、一份确定的调度、两层 SDK，以及一个运行它们的宿主。计划里有十四个内建检查，每个都有阶段、编号和被跳过的理由。只提供建议的检查只能提问；声称给出证据的检查必须满足义务的接受集合，而目前还没有义务接受外部证据。现在加一条检查就是登记一下；框架的公开版本停在零，直到证据面不再移动。

工作台上的两张设计

有两件事目前只是设计，背后没有代码。第一件把借用与域接起来。此前已经存在三种生命周期——值住在哪里、它的时间窗是否仍然有效、谁有权写——它们彼此不说话。新的规则集把借用放进时间窗，要求两侧都具备写权限，并且每条法则只允许一笔独占借用。第二件是编译器加速器。五千行的程序今天要跑大约两秒，前端与检查器占了大头；目标是压到一秒。它会成为第三套实现，它的 IR、ELF 与 Potato 产物必须与参考实现逐字节相同。

还开着什么

自举实现有函数值与效应语法，但还没有类。效应运行期只是窄窄的一片。联合借用检查器与加速器还是纸面。第一篇笔记就是这种形状。规则没有变：两套实现意见一致、门禁证得了，一个特性才算完成；默认构建在新开关点名之前不动。

下一段值得描述的路走完，我再写下一篇。— Loment Dev Fujo
