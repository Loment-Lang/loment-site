Tur 2026.3 第二个完整测试版本：借用生命周期，以及一个补缺口的 store

Tur 2026.3 的第二个完整测试版本已经就绪。借用生命周期进入了两套实现，lgc 让收集器有了时间维度，store 长到 332 个模块，程序可以向它要 Loment 本身不提供的便利。 这一版仍然没有开发完。

这是测试版本，不是发布，Tur 2026.3 也还没有结束。稳定通道仍是 0.1.5.1；在线编译的 Beta 通道跟 main。下面写成“下一步”的东西是方向， 不是日期。

测试版本声明的是什么

测试版本把整个版次放在一起、一次跑通：两套编译器实现、两条产物路径、以及完整的 store。上一个版本带的是域与 LSPE；生命周期是下一条线。这第二个版本第一次让借用 生命周期与扩充后的 store 出现在同一棵树里。它是一个检查点，不是一个 tag。

这个声明很窄，也可以检验：tools/lomentc.py 的参考编译器与 loment/selfhost 的自举编译器读同一套 Tur 2026.3 表层，对语料发出同一份 IR。两边不一致，这个版本就不算完成。

借用生命周期，不用生命周期语法

&T 与 &mut T 现在是一等类型：形参、返回、结构体字段 与泛型实参都能写。维度是 choose lifetime_no | lifetime_auto | lifetime_manual。从 tur2026.3 起默认 lifetime_auto；旧版次仍默认 lifetime_no，所以它们的产物一个字节都不变。

表层保持安静。一个借用输入意味着所有借用输出都从它借；多个借用输入加一个输出时取 最短的那个，所以 fn min(a: &[u32], b: &[u32]) -> &[u32] 不需要任何标注。方法从 self 借。只有返回必须指定某一个输入时，才写那个 形参的名字，例如 -> &a [u32]。借用进产物时是一个 ptr；切片借用归一成现有的视图；*r 解引用， r.field 自动解引用。

自举侧在 2026-11-08 跟上了：它不再因为“见到借用类型”本身发 E041。E041 现在只在 区域不成立时出现 —— 返回借用却没有借用形参、区域标记写在不存在的形参上、或者 p 仍被借时 free(p)。存下来的 &mut 会挡住 后来的借用，报 E007。两侧是同五条规则。

诚实的边界。借用作泛型实参只有参考侧支持；自举侧的登记是名字级的， 只有 let x = &mut y 这一种形状进独占表。设计在 docs/299。

lgc 给收集器一个时钟

Tur 2026.3 的另一项特性是 lgc：手动控制收集器的时间。 lgc start(10ms) { … } 打开一个带协作式时间预算的收集窗口； lgc start { … } 打开一个不带预算的窗口；lgc end; 暂停， lgc start; 恢复。lgc end { … } 是词法作用域内的暂停， 出块时恢复进入前的状态。

它在每一种 choose gc 档位下都成立；no_gc 加 lgc 是 E039，因为没有收集器可控制。预算只管开始一次收集， 不会抢占已经在跑的收集。它不是第四档 —— choose gc 仍然是档位选择。

store 长到 332 个模块

Loment 是故意小的。store 是便利所在：普通的 Loment 源码，由两套实现编译，每个公开 名字都列在 docs/store-index.md。 它现在有 13 个包、332 个模块、2791 个公开函数。std 占 148 个；其余是 os（44）、system（41）、world（22）、 dev（15）、lowlevel（12）、internet（11）、 math（9）、host（8）、science（6）、 baremetal（6）、windows（6）与 engineering（4）。

最近一批补上五个结构性缺口。密码学与网络增加了 ChaCha20、Poly1305、AEAD、 AES-CTR/GCM、x25519 与 ed25519，还有带 SCM_RIGHTS 的 AF_UNIX，以及 TLS 1.3 客户端核心。组合层增加了事件循环、原子文件操作、有界 channel、任务队列和 一个小型 HTTP 服务器。windows 包把 Kernel32 的表面写成声明。共享模块 替换了 os 与 system 内部的重复代码。一份生成的索引和一份 按任务组织的 cookbook 让 store 不必读遍每个文件也能查。

store 不掩盖的事。TLS 模块是客户端核心，不声称能与真实服务器互通。 windows 模块在 PE FFI 落地之前只是声明面 （#1262）。Loment 没有函数指针，所以事件循环按 tag 分派，HTTP 服务器返回 handler id。 thread_spawn 需要编译期函数名，所以 job queue 只给你一个队列，worker 自己写。

仍然缺什么

Tur 2026.3 还没有封版。lifetime_manual 接受 &a T 标记， 但更宽的标注面还没有。扩展域、图模型的实体部分、→ / ≺ / × 三种域形式，以及 wasm32 后端，仍然是设计或更晚的工作。store 的平台与 协议边缘被写成边界，而不是填满。

第二个测试版本是“可以把这一版当成一个整体来试”的点。它不是“这一版做完了”的点。
