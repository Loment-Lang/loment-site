有史以来最大的一次扩充

很显然，如果你一直在看仓库，会发现一长串 PR 排在那里。是的：项目正在经历有史以来最大的一次功能扩充，规模超过 0.1.5。过去两周有几十个改动合入，还有十几个开着；这篇笔记把两堆都走一遍。

笔记记录一个时刻，不是一次发布。下面每一个开着的改动都在审阅中；有些会按原样合入，有些会变形，还有一个只是生成物刷新。稳定版仍是 0.1.5.1。

表层语法变短了

Tur 2026.3 现在有一整批语法。先到的是字符串插值：f"a{x}b" 与 rf"..." 由前端改写成 str_concat 调用，词法器、解析器和代码生成器都不认识新节点。接着是格式说明——{x:>8}、{x:<8}、{x:^8}、{x:08}——以及具名字符串常量 const NAME: str = "...";。str_num 现在接受所有整数类型，包括无符号。

然后是控制流的便利写法。if 与 match 表达式可以放在整个 let 初始化表达式里；catch |e| { … } 与 catch return 给错误两种形状；let x := e 与 let x: auto = e 在初始化表达式写出类型时做推断；args(i) 暴露进程命令行。每一条都受版次约束：旧版次照旧拒绝同样的文本，两套实现发出相同的 IR。

函数成了一个值

函数指针、闭包与间接调用落在 choose fp 后面，这是第九维。裸函数名是一个值；闭包按值捕获，写明引用时按引用捕获；通过值调用与按名字调用的写法一样。默认构建一个字节都不变。开关打开后，编译器收集被取地址的目标，并拒绝找不到同类型目标的间接调用。现在有一条运行时判据，让闭包程序过两只链接器。

类，以及一个审计框架

类梯子从布局走到了派发。C1 把类降成结构体：父类字段在前，方法变成普通函数；C2/C3 加了 vtable、虚派发、super、抽象方法与闭世界目标检查。虚类需要 runtime，自举实现还在追——这就是开着的 C4a：把非虚类带到自举侧，并配三条逐字节相同的夹具。

在它下面，审计框架变成了真正的框架：注册表、确定的调度、两层 SDK、十四个内建检查、每个引擎的跳过理由与预算。效应站点现在进 Potato 台账。框架的公开版本停在零，直到证据面冻结。

效应：先有声明，再有一片能跑的

效应声明已经能解析一阵子了。运行期那一半分几步到：lspe_effects_true 后面的参考前端、自举侧镜像、台账里的 E11 站点，然后是一小片真正执行尾续处理器的实现——把它内联成普通语句。没有续体对象，也不碰堆。开着的 A3b 把这一片加宽：分支可以读外层局部变量，以 return e; 收尾的分支会中止。降级刻意做到不带名字，好让自举侧照着镜像；在它落地之前，自举实现仍报 E0217。

借用，分批落地

借用系统是流水线式落地的。设计把区域、时间窗与写权限接在一起；检查器成了按位置键控的 loan 图，最后一次使用就是 kill 点；切片成为结构体字段；存进字段的 &mut 会挡住之后的借用；不相交的字段不再互撞。这个窗口里 B1 合入：slice_len 接受 &[T; N]，切片借用上也能写来源标记。开着的 B2+B3 带着下两批——由调用返回的借用按被调方摘要登记、存下的 &mut 只能用一次、从结构体字段移出会被追踪。此前堆叠的两版被关掉，改在新错误表上重新落地。

域，以及下一个安全故事

域有了显式的同级边，读者能分辨“声明为同一层”和“碰巧挨着”；domain:for 现在拒绝空范围，不再接受一条什么都不覆盖的规则。域与借用联合检查器的设计已经合入：借用必须落在时间窗里，写权限要在两侧都成立，每条法则只允许一笔独占借用。

一份开着的 safety 研究把这个方向推得更远。它量了安全子集里三处不检查的访问——字面量数组越界下标、动态切片下标、裸 load8——指出连今天的陷阱路径也是一个信号（ud2，SIGILL），并提出四层方案、一套故障 ABI，以及产物里逐站点的 fault ladder。

Flomtc：编译器的第二个引擎

Flomtc 起初是一份设计：把五千行程序编到一秒以内。维度与独立可执行文件已经合入；开着的是第一次真正的优化：prepare 的快路径在有泛型声明但没人用时跳掉整模块深拷贝，Potato 事实从五趟 AST 走成一趟，字符串改写加一条恒等快路径。在目标程序上量出来，冷编译从约 2.1 秒降到约 1 秒，原生编译器从 15.8 秒降到 466 毫秒。它在 choose flomtc_true 后面，而且不写进 Potato——它说的是产物怎么做出来的。

另一条研究线问的是另一个问题：程序的启动工作能不能搬进构建里，让运行期从准备好的状态开始。那条线还停在纸面与探针上。

缺陷清扫与门禁

开着的列表也在清缺陷积压的顶部。十四个 sev-0 与 sev-1 全部关掉，其中七个是对着当前 main 复核过的。GC alpha 的根记账修了：每个提升到栈上的缓冲区占一个根，而不是每个字占一个——以前 8 KB 就能把 1024 槽的表填满，然后静默中止。错误报告器的真源移到自举侧，并配了一个完整正则引擎去分类消息文本。诊断行号对齐的缺口归零。

开着的改动接着扫：两只链接器里 getelementptr 首下标的 bug（有状态能力会读到邻居的状态）、PE 的 openat 标志语义、钉死的热更新信任锚、GC 测量工具、五个工具 bug，以及十一个 Java 前门问题。基础设施这边，门禁的 stage1 上限在 CI 实测分片负载下要 330–420 秒之后抬到 900 秒，分片重排；还有一个开着的改动加上 merge queue 需要的 merge_group 触发。

新版本正在审阅

一个开着的改动开启了下一个版次：tur2027.1Alpha，带块作用域。每个花括号块都是词法作用域，嵌套块可以遮蔽，同一块里第二次 let 是 E013，lspe pass、lgc 时间窗与 domain 块也是作用域。它还加了一个专用 GC 检查器，配 ReclaimScoped 义务。默认版次仍是 Tur 2026.3。

这一堆加起来是什么

把清单放在一起，形状很清楚：一批语法、函数值、两套编译器里的类、能跑的效应、借用的最后几道缺口、域的几何、第二个编译引擎、缺陷积压的顶部、一份安全设计，以及门禁前的一条队列。这一波比 0.1.5 大，因为功能下面那一层在同时重铺。它们没有一样在稳定版里。规则没变：两套实现意见一致、门禁证得了，一个改动才落地；默认产物只在新开关或新版次点名时才移动。

下一篇笔记会说哪些合入了。— Loment Dev Fujo
