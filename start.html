Learn Loment

Install the package, get one program to run, then pick the route that matches how you work: two books — one for using Loment, one for changing it — an example set, or a course of exercises. Every program in them is compiled and run by the gate. Underneath all of it sits the other teacher: a toolchain that explains itself, which can print the whole language, list every built-in function, and tell you what any diagnostic means.

Read the book Open the Playground

The teaching exists; what is missing is translation. The Loment Book, the Development Contribution Plan, By Example and Lomentlings are English; the reference manual and the design records are still Chinese. Where a resource below is incomplete, this page says so rather than letting you find out.

Install it

Loment ships as a package. Take the archive for your platform from the latest release.

Linux / WSL

A linux-x64.tar.gz. Unpack it and run sh install.sh. POSIX sh is the only requirement.

Windows

A windows-x64.zip — unpack it and run powershell -File install.ps1 — or a windows-x64-setup.exe you double-click.

You get the loment command, the package manager (lompi), and the language server. Compiling and running needs no Python, no clang and no WSL: the package is native binaries plus the standard library, and the installer checks SHA256SUMS before it writes anything.

To change the language itself rather than use it, work from a checkout instead: git clone https://github.com/Loment-Lang/loment.git. The compiler is written in Loment and rebuilds from a seed committed to the repository — sh loment/bootstrap.sh builds it and checks that the seed reproduces itself byte for byte.

Write a program

Put this in hello.lomt. 

module hello fn _start() {    let s: str = "hello from Loment\n";    syscall4(1, 1, str_ptr(s) as u64, str_len(s) as u64);    syscall4(60, 0, 0, 0);}

_start is where the machine begins. A sealed program — one that links nothing — has no runtime underneath to call an entry point for you, so you name it yourself; and it has no printf, so output goes through the write system call: the file descriptor, the string's pointer, and its length. The second call is exit. Write choose hosted instead and you get an ordinary C program, with fn main() -> u32 as its entry point.

Compile and run it

$ loment run hello.lomt          # compile, link, run$ loment build hello.lomt -o hello$ loment check hello.lomt        # check only, nothing written$ loment ir hello.lomt           # the LLVM IR it generates

On Windows the target is PE, so name the output .exe — the linker picks the format from that name. loment new hello writes this starting point for you, and will not overwrite an existing file.

Choose a way in

Two books and two practice tracks, one language. Pick the one that matches what you need; all of them live in the repository, and every program in them is checked by the build.

The Loment Book

Nicknamed “the book”. It gives you the language from first principles and builds a few projects along the way, so that by the end you have a working model of the syntax, the capability domains and what the compiler does with your source.

Read the book

The Development Contribution Plan

The second book: the repository map, the gate and its ratchets, the two compilers and their seed, the bootstrap chain, releases and an architecture tour. Read it when you want to change Loment, not just use it.

Read the contribution plan

Loment by Example

One concept per file, each a short annotated program that compiles and runs. Use it when you need a working shape rather than an explanation.

Check out By Example

Lomentlings

Small broken programs to fix, one idea each, with a runner that tells you when you are done: python tools/lomentlings.py. It makes the syntax stick.

Do the Lomentlings course

The toolchain explains itself

This is the part that is genuinely unusual, and it is worth trying even if you have no intention of using the language. The toolchain is the reference. Every one of these reads from the installed package, so they work with no network, and they answer about the version you actually have. 

$ loment example tour   # the whole language in one file$ loment cheat          # the whole language on one page$ loment builtins       # every built-in function there is$ loment syntax         # syntax summary$ loment explain E4     # what a diagnostic means, and what to change

The tour's comments are in Chinese, and on the currently published release that file does not link; the programs on Examples are the ones verified to run. The other four commands are in English.
