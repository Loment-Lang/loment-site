What this page runs

    
The source is compiled by the repository's reference compiler, then executed by LVM, the interpreter the project uses for its deterministic runtime tests. Both steps happen in this browser tab.

    
Boundaries. The first run downloads about 20 MB of engine. A program may use fn main() or fn _start(). Standard input, files and sockets are unavailable, and a step cap stops a runaway loop. Diagnostics are the compiler's own messages.

    
For the native toolchain, start at Get started. More programs are on Examples.
