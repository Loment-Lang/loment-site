Blog · 2026-11-20

The largest expansion yet

Clearly, if you have been watching the repository, you will have noticed a long line of pull requests. Yes: we are in the middle of the largest feature expansion the project has ever carried, larger than 0.1.5. The last two weeks produced dozens of merged changes and a dozen open ones; this note walks through both piles.

A note about a moment, not a release. Every open change below is in review; some will merge as written, some will change shape, and one is a generated-artifact refresh. The stable release is still 0.1.5.1.

The surface got shorter to write

Tur 2026.3 now has a full syntax batch. String interpolation arrived first: f"a{x}b" and rf"..." are rewritten by the front end into str_concat calls, so the lexer, parser and code generators never learn a new node. A format spec followed — {x:>8}, {x:<8}, {x:^8}, {x:08} — and named string constants, const NAME: str = "...";. str_num now accepts every integer type, unsigned included.

The control-flow conveniences came next. if and match expressions work as a whole let initialiser; catch |e| { … } and catch return give errors two shapes; let x := e and let x: auto = e infer the type when the initialiser spells one; args(i) exposes the process command line. Every item is edition-gated: older editions reject the same text exactly as before, and both implementations emit the same IR.

A function became a value

Function pointers, closures and indirect calls landed behind choose fp, the ninth dimension. A bare function name is a value; a closure captures by value, or by reference when the reference is named; calling through a value is spelled like calling by name. The default build does not change a byte. With the switch on, the compiler collects address-taken targets and rejects an indirect call with no target of its own type. A runtime criterion now exercises closure programs through both linkers.

Classes and an audit framework

The class ladder went from layout to dispatch. C1 lowered classes to structs with parent fields in front and methods as ordinary functions; C2/C3 added vtables, virtual dispatch, super, abstract methods and the closed-world target check. Virtual classes need a runtime, and the self-hosted compiler is still catching up — that is the open C4a change, which brings non-virtual classes to the self-hosted side with three byte-identical fixtures.

Underneath, the audit framework became a framework: a registry, a deterministic schedule, two SDK tiers, fourteen built-in checkers, per-engine skip reasons and budgets. The effect sites now enter the Potato ledger. The framework's public version stays at zero until the evidence surface freezes.

Effects: declarations, then a slice that runs

Effect declarations had parsed for a while. The runtime half arrived in stages: a reference front end behind lspe_effects_true, a self-hosted mirror, the E11 sites in the ledger, and then a narrow slice that actually executes tail-resumptive handlers by inlining them into ordinary statements. No continuation object, no heap. The open A3b change widens the slice: arms may read enclosing locals, and an arm ending in return e; aborts. The lowering is deliberately name-free so the self-hosted side can mirror it; until that lands, the self-hosted compiler still reports E0217.

Borrows, in batches

The borrow system has been landing as a pipeline. The design joined regions, time windows and write authority; the checker became a loan graph keyed by place, with the last use as the kill point; slices became struct fields; a &mut stored in a field excludes later borrows; disjoint fields stopped colliding. B1 landed in this window: slice_len through &[T; N], and the source marker on slice borrows. The open B2+B3 change carries the next two batches — a borrow returned by a call registered from the callee's summary, a stored &mut usable exactly once, and moves out of struct fields tracked. Two earlier stacked versions of that work were closed and re-landed on the new error-table source.

Domains, and the next safety story

Domains gained explicit sibling edges, so a reader can tell a declared same-layer pair from an accidental one, and domain:for now rejects an empty range instead of accepting a rule that covers nothing. The design for the joint domain-and-borrow checker landed: a borrow has to sit inside a time window, write authority has to hold on both sides, and each law allows one exclusive loan.

An open research document pushes the same direction further. It measures three unchecked accesses in the safe subset — a literal array index out of bounds, a dynamic slice index, a raw load8 — notes that even the current trap path is a signal (ud2, SIGILL), and proposes four layers, a fault ABI and a per-site fault ladder in the artifact.

Flomtc: a second engine for the compiler

Flomtc started as a design for compiling five thousand lines in under a second. The dimension and a standalone executable landed; the open change is the first real optimization: a prepare fast path that skips a whole-module deep copy when generics are declared but unused, one AST walk instead of five for the Potato facts, and an identity fast path in the string rewrite. Measured on the target program, cold compile goes from about 2.1 s to about 1 s, and the native compiler from 15.8 s to 466 ms. It sits behind choose flomtc_true, and the dimension is not recorded in Potato because it says how an artifact was made.

A second research line asks a different question: whether a program's start-up work can be moved into the build, so the runtime begins from a prepared state. That one is still paper and probes.

The defect sweep and the gate

The open list is also clearing the top of the defect backlog. All fourteen sev-0 and sev-1 issues were closed, seven of them verified against current main. The GC alpha root accounting was fixed: one stack-region root per promoted buffer instead of one per word, which used to fill a 1024-slot table on its own and abort silently at 8 KB. The error reporter's source of truth moved to the self-hosted side, with a complete regex engine to classify message text. Diagnostic line parity reached zero gaps.

The open changes continue the sweep: a getelementptr first-index bug in both linkers that made stateful capabilities read their neighbour's state, PE openat flag semantics, a pinned hot-update trust anchor, the GC measurement tools, five tool bugs, and eleven Java front-door issues. On the infrastructure side, the gate's stage1 ceiling rose to 900 s after CI measured 330–420 s under shard load, the shards were rebalanced, and an open change adds the merge_group trigger a merge queue needs.

A new edition is in review

One open change starts the next edition: tur2027.1Alpha, with block scoping. Every braced block becomes a lexical scope, nested blocks may shadow, a second let in the same block is E013, and lspe pass, lgc windows and domain blocks are scopes too. It also adds a dedicated GC checker with a ReclaimScoped obligation. The default edition stays Tur 2026.3.

What the pile adds up to

Put the lists together and the shape is clear: a syntax batch, function values, classes in both compilers, effects that run, the last borrow gaps, domain geometry, a second compiler engine, the top of the defect backlog, a safety design, and a queue at the gate. This wave is larger than 0.1.5 because the layer underneath the features is being rebuilt at the same time. None of it is in the stable release. The rule has not changed: a change lands when both implementations agree and the gate can prove it, and the default artifact moves only when a switch or an edition asks for it.

The next note will say what merged. — Loment Dev Fujo
