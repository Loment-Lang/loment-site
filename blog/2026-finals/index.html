The Finals Of 2026

2026 is closing, and the last stretch has a concrete plan: the 0.1.5.2 official release, the first test build of 0.1.5.3, a better Playground, and another pass over lifetimes and GC timing. This is the long version of that plan — what the year actually built, what ships before the calendar turns, and what remains open.

This is a plan, not a release note. 0.1.5.1 is still the stable channel today. The order is fixed; the day is not. “Official” means a tagged, signed channel, not that every design item is finished.

Where 2026 actually landed

2026 moved the project from 0.1.4 to 0.1.5.1. The surface grammar became a two-level edition system: Tur 2026.1 is frozen, Tur 2026.2 closed in November, and Tur 2026.3 is the open line. That is not a cosmetic version bump. It means a file can pin the reading it was written for, and the newest syntax can move without silently changing older artifacts.

Domains became blocks with a place and a lifetime: you enter a domain, the domain starts; you leave, it ends. All eighteen kinds now ship, and domain:for walks positions; tree and graph edges became syntax too (child_of, couple, mutex). LSPE v2 arrived as four parts: the questioner (E1–E8), the counter-asker (Q001–Q013), the LSPC pre-flight sheet, and a ledger with a proof hash per site and a .lspe sidecar.

Borrow lifetimes arrived without a lifetime syntax. &T and &mut T are first-class in parameters, returns, struct fields and generic arguments; lifetime_auto is the default from tur2026.3 on, and the common cases need no annotation. The self-hosted compiler caught up on 2026-11-08: it no longer rejects borrow types by name, and E041 appears only when a region does not hold. lgc gave the collector a clock: lgc start(10ms) { … } opens a collection window with a cooperative budget, lgc end; pauses, and no_gc plus lgc is E039 because there is no collector to control.

The store grew to 332 modules across 13 packages and 2791 public functions. The last batch added ChaCha20, Poly1305, AEAD, AES-CTR/GCM, x25519 and ed25519, AF_UNIX with SCM_RIGHTS, a TLS 1.3 client core, an event loop, atomic file operations, a bounded channel, a job queue, a small HTTP server and a Windows declaration surface. The Playground put the reference compiler and the LVM in a browser tab; Java libraries became callable without a JVM; hot update became a release-shaped thing; wasm32 became a design record instead of a wish.

That is the year in one page: the language stopped being a set of promises and became a set of artifacts that can be checked, linked and shipped.

The last stretch has an order

The plan for the end of 2026 is deliberately short. First, 0.1.5.2 becomes the official release. The beta line already carries the domain work, LSPE v2, the lifetime dimension, the expanded store and the Playground snapshot. Promotion is not a new feature: it is the point where the channel, the artifacts, the signatures and the notes agree with each other. The stable channel moves only when both implementations read the same surface and the criteria are green.

Then, 0.1.5.3 opens with its first test build. This is a test build, not a release: it is where the next line becomes runnable, and where the things that are still design get their first executable shape. The order matters. A stable 0.1.5.2 first gives the next build a fixed floor; a test build that runs ahead of its own stable channel teaches the wrong lesson.

“Official” has a narrow meaning here. It means the tag, the signed artifacts, the channel that the Playground's Stable side can point at, and a release note that says what is not in it. It does not mean that every open design item is closed. The open list is in the last section, and it stays open until its criteria exist.

Three tracks for the same weeks

Playground

The Playground is the first place most people meet the compiler, so it gets the next pass. The goals are concrete: a faster first load and a smaller snapshot; an editor that keeps line numbers, syntax, diagnostics and selections correct; clearer actions for Run, Check, Build, IR, AST, Potato and machine code; and a layout that works on a phone. The two channels stay. Beta follows main; Stable points at the released tag. The Playground never uploads source, and it does not grow a server.

Lifetimes

Lifetimes are in, but the surface is not finished. The next pass widens lifetime_manual beyond the &a T marker, brings borrows in generic arguments to both implementations, and makes the diagnostics name the source, the line and the path instead of printing a bare “lifetime error”. The zero-annotation cases stay the default; the explicit cases should be rare and obvious, not a second dialect.

GC timing

lgc gave the collector a clock; the next work is making that clock predictable. The budget gates starting a collection, not preempting one already running. The next pass tightens the budget semantics, measures the collector under the four-tier ladder, and writes down what each tier promises under load. no_gc stays a real mode, not a trap: no_gc plus lgc remains E039.

What “finals” means here

A school year ends with finals because the calendar says so. A language does not. The edition is closed when the surface stops moving and the criteria are green, not when December arrives. So “the finals of 2026” is a place to stop and look, not a declaration that the work is over.

0.1.5.2 official is a checkpoint with a tag. 0.1.5.3's first test build is the next line starting to move. Neither one closes Tur 2026.3, and neither one makes the open list disappear. The honest year-end statement is narrower than a launch: the project can now be described in one page without inventing anything, and the next page is already written.

What remains open

The list is not hidden. lifetime_manual still needs its wider annotation surface. Extension domains and the solid body of the graph model remain design. The wasm32 backend is a design record, not a backend you can use. The store's platform and protocol edges are written as boundaries; the Windows modules wait for PE FFI. The five store gaps are still a branch rather than a release. None of them has a date.

The previous test-build note is here; the Playground is here. Everything else is in the repository.

A year is a useful unit for looking back and a bad unit for declaring a language finished. — Loment Dev Fujo
