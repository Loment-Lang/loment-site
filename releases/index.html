Timeline

A timeline, not a changelog

Every Loment release, in order, with one sentence for what it was for. The detailed lists of additions and fixes live on GitHub, where the artifacts and signatures are. This page keeps only the shape of the line.

Download the current release Roadmap

This is the one page on this site that names versions. Everywhere else the download link says releases/latest, because a version number copied onto a page is a fact with an expiry date. Here the dates are the subject.

The line

The first six versions came from the project's previous repository; their tags and dates are not in this one, so they appear without a date. From 0.1.4 onward every entry is a release in this repository.

Major progress Large content update Other releases
before 2026-09

0.1.1

The first Loment: a strict subset of Rust's syntax. The subset claim has since been dropped; the overlapping syntax stayed.

before 2026-09

0.1.2 Alpha

The language begins to be written in itself — the only way to find out what it cannot express.

before 2026-09

0.1.2 pre1

Repairs for the problems the first self-hosting turned up.

before 2026-09

0.1.2 pre2

The bootstrap base that still stands: a compiler rebuilt from a committed seed, checked to reproduce itself.

before 2026-09

0.1.3 Alpha

Another language's source can be read as Loment: the spelling is borrowed, the meaning stays Loment's.

before 2026-09

0.1.3.4 Alpha

Lexer, parser, checker and code generator all written in Loment; the bootstrap reaches a three-stage fixed point.

2026-09-22

0.1.4 Pre

The first installable build. Its point was to turn “the repository has versions” into something you can look at.

2026-09-23

0.1.4

Usable rather than larger: no syntax changed, and the last interpreter path left the build. On Windows, use the zip; that installer is known broken.

2026-10-13

0.1.4.5

The reclamation ladder, no_runtime as a guarantee, networking on both targets, and the vm setting behind a closed gate.

2026-10-17

0.1.4.6

The interpreter tier, libc and LibL, and the vm setting become reachable from a release.

2026-10-18

0.1.4.7

Every shipped library compiles to byte-identical IR in both implementations: 155 modules, none skipped.

2026-10-20

0.1.5

choose becomes a seven-dimension matrix whose legal cells are compiled by both implementations; LMS and LSPE ship.

2026-11-07

0.1.5.1

Capability domains become an algebra of shape, polarity and time law; hot update and Java libraries without a JVM land; tur2026.3 becomes the default edition.
